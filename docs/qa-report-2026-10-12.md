## UI checks and fixes

- At 375px all 12 icon previews load, Moon is initially selected, selection changes
  only after success. Browser preview explicitly says that system icons change in
  the native application. [Screenshot](qa/icons-375.jpg).
- At 320px and 125% text, no horizontal page overflow was measured; nav labels fit
  after shortening Chats and capping navigation label size. Light/dark checked.
- At 768/1440px DOM layout measurements show no horizontal overflow and a bounded
  760px mobile content width. These are layout checks, not physical tablet tests.
- Demo chat opens with composer focus, retains focus after a demo send and clears
  its field. Composer bottom is above nav, with and without a mini player.
- Full player opens from mini player. Shift-Tab/Tab wrap within player. Sleep timer
  is a separate opaque bottom sheet; Escape closes the top dialog first.
- Shared scroll locks fix parent-first/nested-first cleanup. Both orders have
  regression tests; background scrolling is restored after final dialog closes.
- Custom accent control follows the chosen accent; System theme listens for changes.
- Older WebView support: Chrome 89/Safari 15 compilation target, viewport-height
  fallbacks and removal of unsupported at/hasOwn/replaceAll calls in app source.
- Website RU/EN browser review: one H1, correct production canonical, no missing alt attributes or failed completed images; lazy images below the fold were recorded separately.
- Website uses Veirune and Moon, contains RU/EN Android information and a direct
  Android anchor. APK link enables only for a real matching stable mobile release. [Website screenshot](qa/website-android-en.jpg).

- Follow-up website button review: Android actions now align with the section text;
  at phone widths they stack with equal 44px heights. Hero download takes a full
  row, Android/source actions share the next row. RU 375px and EN 320px plus
  desktop 1280px were inspected in browser with no horizontal overflow.
  [Phone screenshot](qa/website-android-ru-mobile.jpg). Website checks: 15 passed.
