Read README.md and docs/architecture.md before changing platform code. Mobile app lives in this repository; the desktop and backend are sibling repositories. Never put SoundCloud client secrets, user tokens, keystores or signing passwords in source control. All SoundCloud metadata, images and playback use the authenticated Fastcloud backend. Native background playback owns its queue, token refresh and listening accounting. Preserve per-account caches and dirty patches; do not overwrite cloud preferences with defaults on first login. Validate Android builds and shared TypeScript tests. iOS requires a macOS build and real-device verification; never claim it tested on Windows. Do not publish or deploy unless the user explicitly authorizes it.
